== NAME

nng_http_reset - reset HTTP connection state

== SYNOPSIS

[source, c]
----
#include <nng/nng.h>
#include <nng/supplemental/http/http.h>

void nng_http_reset(nng_http *conn);
----

== DESCRIPTION

The `nng_http_reset()` function resets the connection state so that it
is just as if it had been freshly created with
xref:nng_http_client_connect.3http.adoc[`nng_http_client_connect()`]
or passed into a handler function for a server callback.
